## Isi gambar

Poster berjudul “THE WORLD TODAY” dengan edisi 18 November 2026, satu lead story, peta dunia, dan tujuh brief berita bernomor: (1) Middle East, (2) Europe, (3) Asia, (4) Asia, (5) Africa, (6) Oceania, dan (7) Americas. Ada pula satu baris “ALSO”. Gambar dibuat oleh agent dan disimpan sebagai PNG 1024 × 1024.

## Menjalankan

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Program menyalin `entry.png` apa adanya ke folder output sebagai `entry.png`. Jika `MAKEFUN_OUTPUT_DIR` tidak diisi, tujuan default adalah `/output`.

- `main.py` — penyalin gambar standar library Python.
